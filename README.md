# Horse Racing Management

Project layout:

```text
horse-racing-management/
├── backend/     Spring Boot
├── frontend/    React
├── README.md
└── .gitignore
```

## Backend

```powershell
cd backend
.\mvnw.cmd spring-boot:run
```

On macOS/Linux:

```bash
cd backend
./mvnw spring-boot:run
```

## Frontend

The `frontend/` directory is reserved for the React app source.
